## ⚠️ Important: Authorized Use Only

This tool is designed exclusively for:
- **localhost** and controlled laboratory environments
- **Intentionally vulnerable** applications (DVWA, WebGoat, Metasploitable, etc.)
- **Test environments** under your ownership
- **Explicitly authorized targets** with written permission

**This tool does NOT perform autonomous exploitation.** It is a decision-support system for human security analysts.

---

## Research Basis

This project implements the concepts from:

> *"LLM-Assisted Security Vulnerability Analysis for Educational Websites: Risk Identification via LLM-EduAttackGraph"*  
> Chao Liu, Jiaxing Liu, Boxi Chen, Daxin Zhu, Ching-Chun Chang, Chin-Chen Chang  
> IEEE Internet of Things Journal, Vol. 13, No. 2, 15 January 2026  
> DOI: 10.1109/JIOT.2025.3631562

The paper introduces LLM-EduAttackGraph, a two-stage system:
1. **Website Fingerprinting** — TCP/IP probing, service identification, web fingerprinting
2. **LLM-Driven Penetration Path Inference** — RAG with BGE embeddings + FAISS + DeepSeek

## Architecture

```
AUTHORIZED TARGET
       │
       ▼
┌─────────────────────┐
│  Fingerprinting      │
│  Engine              │
│  - TCP Port Scan     │
│  - Service ID        │
│  - Web Fingerprint   │
└──────────┬──────────┘
           │ Structured Fingerprint
           ▼
┌─────────────────────┐
│  BGE-m3 Embedding   │ ◄── bge-m3 (multilingual)
└──────────┬──────────┘
           │ Query Vector
           ▼
┌─────────────────────┐
│  FAISS Vector Store │ ◄── Awesome-POC knowledge base
└──────────┬──────────┘
           │ Top-K Results
           ▼
┌─────────────────────┐
│  Cosine Similarity  │
│  Threshold: 0.60    │ (configurable)
└──────────┬──────────┘
           │ Relevant Historical Evidence
           ▼
┌─────────────────────┐     Prompt = Φ(query)
│  RAG Context        │     ⊕ Ψ(best_match)
│  Construction       │     ⊕ Γ(template)
└──────────┬──────────┘
           │ Structured Prompt
           ▼
┌─────────────────────┐
│  LLM Inference      │ ◄── DeepSeek / Groq / NVIDIA NIM
│  (DeepSeek)         │
└──────────┬──────────┘
           │ Potential Vulnerability Analysis
           ▼
┌─────────────────────┐
│  Human Validation   │ ◄── Security analyst reviews
│  (HIIL)             │
└──────────┬──────────┘
           │ VALIDATED / REJECTED / NEEDS_MORE_EVIDENCE
           ▼
┌─────────────────────┐
│  Security Report    │
└─────────────────────┘
```

### Evidence Classification
Every output is clearly labeled:
- **OBSERVED** — Directly obtained from reconnaissance
- **RETRIEVED** — From the RAG knowledge base (Awesome-POC)
- **INFERRED** — Generated by the LLM (not confirmed)
- **VALIDATED** — Reviewed and accepted by a human analyst

## Features

- ✅ Controlled TCP port scanning (Python-native + adapter for port-go.exe)
- ✅ Service and version identification
- ✅ HTTP/HTTPS web fingerprinting
- ✅ BGE-m3 multilingual embeddings
- ✅ FAISS vector database with cosine similarity
- ✅ Configurable similarity threshold (default: 0.6)
- ✅ Awesome-POC knowledge base ingestion
- ✅ Multi-provider LLM support (DeepSeek, Groq, NVIDIA NIM, OpenAI)
- ✅ Human-in-the-loop validation workflow
- ✅ Full evidence provenance and audit trail
- ✅ Structured security report generation
- ✅ Demo mode (no external targets needed)
- ✅ FastAPI backend with OpenAPI docs
- ✅ React/TypeScript/Vite frontend dashboard

## Quick Start

### Prerequisites
- Python 3.11+
- Node.js 18+
- Docker & Docker Compose (for full deployment)
- PostgreSQL (or use SQLite for dev)

### 1. Clone and Configure
```bash
git clone <this-repo>
cd llm-edu-attackgraph
cp .env.example .env
# Edit .env with your API keys and configuration
```

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

### 3. Ingest Knowledge Base
```bash
# Clone Awesome-POC
cd rag
python ../scripts/ingest_knowledge_base.py --source awesome-poc --path ./data/raw/awesome-poc

# Build FAISS index
python ../scripts/build_faiss_index.py
```

### 4. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 5. Docker (Full Deployment)
```bash
docker-compose up -d
```

## Configuration

See [.env.example](.env.example) for all configuration options.

Key settings:
```env
SIMILARITY_THRESHOLD=0.60      # RAG relevance threshold (paper default)
TOP_K=5                        # Top-K FAISS results to retrieve
EMBEDDING_MODEL=BAAI/bge-m3   # Multilingual embedding model

LLM_PROVIDER=deepseek          # deepseek | groq | nvidia | openai | mock
DEEPSEEK_API_KEY=your-key-here
GROQ_API_KEY=your-key-here
NVIDIA_API_KEY=your-key-here

AUTHORIZED_TARGET_MODE=allowlist    # strict: only allowlisted targets
TARGET_ALLOWLIST=localhost,127.0.0.1,::1
```

## Limitations

1. **Logical/business-flow vulnerabilities** are not supported (paper acknowledges this)
2. The tool **does not execute exploit payloads** — it provides analysis only
3. LLM outputs are **INFERRED**, not confirmed findings — human review is mandatory
4. Performance results from the paper were obtained on Chinese educational websites; this implementation has not independently reproduced those results
5. `bge-m3` is used instead of `bge-small-zh` (paper's model) for better multilingual coverage

---

## Security Restrictions

- Only allowlisted targets may be scanned
- SSRF protection is enforced
- LLM has no shell execution privileges
- Retrieved knowledge base content is treated as untrusted data
- All scans are audit-logged
